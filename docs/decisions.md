# 決めたことと理由

## 2026-11-12 開発の立ち上げ

- **名前は「目押し成金」**。リポジトリ名は `meoshi-narikin`。
- **構成はアストラクロニクル（Zodiac-Puzzle-Battle）と同じ**：TypeScript ＋ Vite ＋ Vitest、GitHub Actions で GitHub Pages に公開、作業ブランチ → PR → main。
- **試作品の画面はそのまま移した**（`src/ui/app.ts`、型チェックなし）。エンジン（停止制御・抽選・生活の計算）と数値だけ先に `src/game/`・`src/data/` に分け、停止制御の約束をテストにした。画面は作り直すときに分割して型を付ける。
- **保存は端末内（localStorage）**。試作品と同じキー（`meoshi-narikin-v1`）なので、同じブラウザなら試作品の続きから遊べる。

## 試作の段階で決めたこと（仕様書 11章の経緯の詳細）

- **終わりのない成長**：日数で終わるローグライクにはせず、少しずつ（大幅にではなく）良くなる要素を積み重ねる。
- **バトル要素はなし**：モンスターと戦う形（封印リール）はやめ、スロッターの生活に絞った。
- **7とBARは大きく、5ライン、BAR狙い**：日本のスロットの見た目と打ち方に寄せるため。
- **ボーナスは 7・7・7（BIG）と 7・7・BAR（REG）**：左と中は共通、右で見分ける実機の感覚に合わせた。
- **左にスイカが見えたらスイカ以上**：BAR狙いで左にスイカが滑ってきたらレア役、という実機の常識に合わせた。
- **表示と払い出しを必ず一致させる**：当たっていないのに役がそろって見える状態は整合性が取れないため、先読みの停止制御と配列の組み直しでなくした。変則押しのときだけ、実機同様に取りこぼすことがある。
- **バイトは作業ミニゲーム**：ボタン1つで稼げるとスロットを打たなくなるため、検品作業の出来高制にし、スロットより割に合わない程度にした。
- **ホールは各機種3台の9台**：1機種1台では台選びが成り立たないため。普段は他の客が座っていて、イベント日は整理券の番号で選べる台が決まる。
- **ハマりの持ち越しは店ごとのリセット率で決まり、店員さんとの仲で情報が見える**：ハイエナと朝一の立ち回りに読みの要素を入れるため。

## 2026-11-15 部屋4枚・観葉植物・台の部品を絵にする

- 1K・分譲マンション・一戸建て・タワマンの背景と観葉植物を劇画風の絵に差し替え、部屋と家具はすべて劇画風になった。
- 台は1枚の絵にせず、部品ごとに絵を作って組み合わせた（ユーザーの提案）。リール・液晶・カウンターは目押しの判定や数字の更新があるのでプログラムで描き、その周りの枠・ボタンを絵にした。画面の長さが変わっても切れないよう、台の地と LED の柱は繰り返して並べる。
- 絵の場所は base のパスを付ける必要があるので、CSS に直接書かず、起動時に JS から CSS の変数（--c-*）に入れる。
- ストップボタンは押せる範囲を受け皿の穴より広くとり、押しやすさを保った。判定は押した瞬間の時刻で、見た目の変更は影響しない。

## 2026-11-15 台を画面いっぱいに出し、ほかは右の引き出しへ

- 部品の絵を並べた台は「ハリボテ感」がある（ユーザーの指摘）。部品ごとのすき間や重なりがそろわないのが原因なので、台全体を1枚の絵にし、液晶・リール・カウンター・ストップボタンの部分だけを窓にしてプログラムで描く（ユーザーが選んだ）。窓は緑一色で描いてもらい、こちらで切り抜く。
- 台を画面いっぱいに出し、所持金・ゲージ・オート・やめるなどは全部、右から引き出すメニューに入れる（ユーザーが選んだ。引き出しは右から）。
- オートを止めるボタンも引き出しの中になるので、オート中はつまみを金色にして「オート中」と出す。
- 打っている間に画面を作り直しても、開いていた引き出しは開いたままにする。ただしオートを始めたら閉じて台を見せる（リールや液晶の知らせが見えるように）。
- 引き出しが開いている間は後ろの台を操作できないようにする（キーボードのレバー・ストップも止める）。
- ストップボタンの押せる範囲は、隣のボタンと重ならない大きさ（丸の直径の1.25倍）にする。重なると、押したつもりと違うリールが止まって押し順が変わってしまうため。
- 体調不良・空腹で目押しに影響が出ているときの知らせは、引き出しだけでなく台のリールの下にも出す。
- 縦画面向けなので、横向きで台が小さくなるときは縦にするよう知らせる。
- 参考画像の液晶の人物とメダルの受け皿は、前の決めごと（液晶は機種のバナー、受け皿なし）のとおり入れない。
