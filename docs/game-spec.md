公開版：https://high-valley.github.io/meoshi-narikin/ 　試作品（参考用の単一ファイル）：`prototype/narikin.html`
数値はすべて調整前の暫定値。コードでは `src/data/` に置く。

## 1. コンセプト

- 主人公はボロアパートの6畳一間に住むスロッター。架空のホールで架空のスロットを打ち、ゲーム内のお金で暮らしを良くしていく生活シミュレーション。
- 腕前（目押し、ビタ押し、台選び）が収支に直結する。運の台と腕前の台を作り分ける。
- 終わりはない。少しずつ、でも大きくは強くならない成長要素で、ずっと良くなっていく。
- **現実のお金・景品には一切換わらない。** 課金でメダルや抽選を買う仕組みは作らない（賭博との区別、ストア審査のため）。

### 対象と表現上の注意
- ストアでは「疑似ギャンブル」として年齢区分が上がる前提（地域によっては18歳以上）。
- 実在の機種名、メーカー名、キャラクター、告知ランプ、リール配列は使わない。図柄は7、BAR、ベル、リプレイ、スイカ、チェリーなど一般的なものと独自のものだけ。
- 改造基盤など不正行為の要素は、ゲーム内でも罰がある形でのみ扱い、「現実の不正は犯罪」と画面に明記する。

## 2. 1日の流れ

1. 朝、部屋で行動を選ぶ。
   - パチ屋へ行く（1日1回、閉店まで）
   - 日雇いバイト（1日1回、パチ屋と排他）
   - ごはん、息抜き、家具屋、不動産屋、自己投資、裏市場、実績（いつでも）
2. パチ屋：店を選ぶ → 島から台を選ぶ → 打つ → やめる（換金）。
3. 夜、ごはん等で回復して「寝る」で翌日。

時刻：開店10:00、1ゲーム＝1分として表示、22:40で閉店（最大760G）。

## 4. リール

### 4.1 基本（実機準拠）
- 21コマ、1周0.75秒（約80回転/分）、1コマ約36ミリ秒。
- レバーを叩くと、3本そろって0.15秒かけて全速まで加速する。ストップボタンは全速になってから受け付ける（実機と同じ）。
- ボタンを押してから最大4コマ（約143ミリ秒）滑る。
- 判定は押した瞬間のイベント時刻で行い、描画の遅れに左右されない。
- 有効ライン5本：上段・中段・下段・右下がり・右上がり。
- 7とBARはリール幅いっぱいの大きな図柄、他の図柄は小さめ。BARは黒地に金の、傾けない横長の板（赤く傾いた7と色も形も見分けられるように）。
- ボーナス図柄（赤7・BAR）は、実機のようにリール上で枠ごと裏から照らして（金色の明かり）狙いやすくする。ほかの図柄は枠の7割ほどの大きさ。図柄は画像（`public/symbols/`）で、読み込めるまでは手描きの図柄を出す。

設計の約束：
- 左のチェリーはBARの真下。スイカは左でBARの3コマ上、中でBARの2コマ上、右はBARの2コマ上ともう1か所。→「BARを上段に狙う（BAR狙い）」でチェリー・スイカを取りこぼさない。
- 右リールは赤7の2コマ上にBAR → 右に7を狙うと、REGの時はBARが滑ってくる。
- 左の「赤7・リプレイ・赤7」（0〜2番）が福招きBIG中のビタ押しポイント。
- 赤7は左に2つ、中に1つ（10番の赤7はベルに置き換えた）。右は赤7とBARが1つずつで、1周に1か所だけまとまっている（「7・リプレイ・BAR」が狙う目印。ほかの赤7・BARはリプレイとベルに置き換えた）。

### 4.3 停止制御
- 当たっている役（フラグ）の図柄を、すでに止めたリールとラインがつながる段へ最大4コマ引き込む。
- **先読み**：止める瞬間に、残りのリールがどのタイミングで押されても矛盾なく止められる止め方を選ぶ。
- **守られる約束**
  - 順押し（左から止める）なら、何も当たっていない時に役がそろって見えることはない。ベルとリプレイは必ずそろう（全パターンを計算して確認済み）。
  - 変則押し（左以外から）は約1%でベル・リプレイを取りこぼす。実機同様の仕様として明記。
  - 押し順にかかわらず、スイカ以上（スイカ・ボーナス）が当たっていない時、左リールにスイカを止めない。チェリーも当たっていない時は左に出さない。
  - ボーナス開始の形（7・7・7 / 7・7・BAR）は、そのボーナスが始まる時以外に出さない。BARが一列に並ぶのはボーナス当選中の「リーチ目」として許可。
- 払い出しは常に画面にそろった役どおり（表示と枚数が食い違わない）。

## 5. 台（3機種）

共通：1ゲーム3枚。リプレイ 1/7.3（再遊技＝3枚戻し）。設定1〜6。

| | 福招き | 三択侍 | 八門 |
|---|---|---|---|
| 性格 | 目押し・ビタ押しで差がつく | 運の台（押し順3択） | 荒い。ビタ＋8択 |
| ベル | 1/7.5、8枚 | 1/4、押し順3択（正解9枚／不正解1枚） | 1/6、8枚 |
| チェリー | 1/28、4枚（左のどこでも） | 1/40、2枚 | 1/40、2枚 |
| スイカ | 1/50、12枚（1ライン） | なし | なし |
| BIG系 | 1/(240−12×設定) | 1/(300−17×設定) | 1/(275−18×設定) |
| REG | 1/(340−12×設定) | なし | 1/(460−12×設定) |
| チェリー重複 | 20%でボーナス同時当選 | 10% | 10% |
| 天井 | 800G | 700G | 900G |

### 5.1 ボーナスの告知とそろえ方
- 当選すると半分はレバーオン時、半分は全リール停止後にランプで告知（後告知）。
- 告知は「ボーナス確定　左と中に7、右は7を狙う（BARが来たらREG）」。BIGかREGかは教えない。
- 左と中は赤7、右が赤7ならBIG、BARならREG。5ラインのどれでもよい。そろうまで毎ゲーム3枚で挑戦。
- 三択侍は7・7・7で「侍ラッシュ」。

### 5.2 ボーナスの中身
- **福招きBIG（10G）**：毎ゲーム左リールから。左は滑らない。上から7・リプレイ・7の形（中段リプレイ）でビタ止めできれば32枚、外すと15枚。左リールが金枠で光り、他のリールは暗くなる。成功で左リールが白く光る。
- **REG（6G）**：毎ゲーム15枚。
- **侍ラッシュ（50G）**：押し順ナビあり。ベル1/1.3で9枚。終了時に継続をかけた3択（正解で+30G）。
- **八門 扉チャンス**：前兆3G。中リールに赤7が止まれば扉が1つ、中段に滑りなしで止めれば2つ消える。最後に8つの扉から1つ選ぶ。当たり600枚、外れ150枚。

### 5.3 チェリー・スイカの読み方
- 左にチェリーが止まれば4枚（福招き）。重複していれば停止後に「チェリー重複」でボーナス確定。
- 左にスイカが見えたら、スイカかボーナスが確定。ランプが「中と右もスイカを狙え」と出す。そろわなければボーナス。

### 5.4 自動消化（10G・100G回す）
- 目押しをしない適当打ちとして計算：チェリー67%で取得、スイカ18%で取得、三択は1/3で正解。
- ボーナス当選・天井到達・チェリー重複で止まり、手打ちに戻る。
- 自動中のリール表示は、役がそろって見えない・左にチェリーやスイカが出ない停止位置を使う。
- 回している間はオートのボタンが「止める」になり、押すとそこで止まる。

### 5.5 機械割（計算値）
| 台 | 適当打ち | BAR狙いができる | ビタまで決まる |
|---|---|---|---|
| 福招き | 約77% | 約94% | 約109% |
| 三択侍 | 約95%（腕前に関係なく） | | |
| 八門 | 約90% | | 約108% |

※ 中と右の7を1つにする前（2026-11-12）の計算値。ボーナスをそろえるまでのメダルが増えたので、適当打ちの値は下がる。八門は扉チャンスで中に赤7が止まる割合も約67%→約33%（適当に押した場合）に下がるので、さらに下がる。数値を詰めるときに計算し直す。

## 6. ホール

| 店 | 1枚 | 解放条件 | 朝のリセット率 | 差し入れ |
|---|---|---|---|---|
| パーラー小銭 | ¥20 | 最初から | 45% | ¥2,000 |
| 駅前メガホール | ¥100 | 所持金が一度でも¥50万 | 65% | ¥5,000 |
| 会員制サロン金鯱 | ¥1,000 | 分譲マンション以上に住む | 25% | ¥20,000 |

- メダルは50枚単位で借りる（足りなくなると自動）。やめる時に等価で換金。

### 6.1 島と台
- 各店、福招き・三択侍・八門の島に3台ずつ、計9台（101〜109番）。
- 台ごとに：設定、前日の総回転数・BIG回数・BIG確率、今のハマり回転数、空き／使用中。
- 普段の日は他の客が2〜3台に座っている。
- 自己投資「データ分析」でREG回数、前日の差枚、高設定の気配（6割の精度）が見える。

### 6.2 天井とハイエナ
- 最後の当たりから天井の回転数まで回すと、必ずBIG系に当選（三択侍はラッシュ）。
- 設置状況の表の「ハマり」が今のハマり回転数。天井の6割を超えると金色。実績「ハイエナ」を持っていると、天井が近い台に「狙」の印が付き、行が金色に光る。

### 6.3 ハマりの持ち越し（リセット／据え置き）
- 毎朝、台ごとに店のリセット率でリセット（0Gから）か据え置き（前日の閉店時の回転数のまま）が決まる。
- 自分が前日に打った台は、自分がやめた時の回転数が閉店時の回転数になる。前日に来店していない店は新しく作り直す。

### 6.4 店員さんとの仲（友好度 0〜100）
- 初期10。来店するたびに+2（1日1回）。差し入れで+8（1日1回）。改造基盤が見つかると−40。
- 仲に応じて朝のリセット情報がもらえる。

| 仲 | もらえる情報 |
|---|---|
| 0〜29 | なし |
| 30〜59 | 「うちはリセット多め／少なめ」 |
| 60〜89 | 「だいたい○%くらい」 |
| 90〜 | 台ごとにリセットか据え置きかが分かる |

### 6.5 イベント日と整理券
- 7のつく日（7、17、27…日目）がイベント日。部屋に次のイベントまでの日数を表示。
- 設定の出方：普段 1〜6＝30/25/20/12/8/5%、イベント日 10/14/20/22/18/16%。
- イベント日は入店前に整理券（1〜150番）を引く。番号12人ごとに1台、先の客が「良さそうな台」（データが良い、天井が近い）から取っていく（最大8台）。

## 9. 保存
- 試作品：ブラウザ内（localStorage）＋公開先ではユーザー専用の保存領域。
- 製品版：端末内保存を基本とする。クラウド保存は後で検討。

### 9.1 アプリの版と更新
- 「自分」タブの「設定」に、今の版（ビルドした日時とコミットの印）と、公開されている最新の版を出す。「最新の版に更新する」（新しい版がないときは「読み直す」）で、保存してから最新の版を読み直す。
- 起動したときと、10分以上たってアプリに戻ってきたときに最新の版を確かめ、新しい版があればホーム画面の上に「新しい版があります［更新する］［×］」の知らせを出す。知らせ（［更新する］付き）はホーム画面にだけ、版の欄と更新ボタンは「自分」タブの「設定」に出す。どちらも、打っている最中やバイト・ルーレットの途中には出さない（打っている最中や、ルーレット・バイトの途中で読み直して結果をやり直せないように）。
- ホーム画面に置いたアプリは閉じても読み直されないことがあるため（アストラクロニクルと同じ仕組み）。

### 9.2 アプリのアイコン

### 9.4 画面の構成と操作
- 画面の下に、いつも4つのタブを出す：**ホーム**（部屋・パチ屋へ行く・日雇いバイト・寝る）／**パチ屋**（店選び→島）／**買い物**／**自分**。打っている最中（打ち終わりの結果まで）・バイト・改造基盤を仕込むか聞く画面とルーレットの途中はタブを隠す（途中で抜けて結果をやり直せないように）。パチ屋は1日1回で、打った後・バイトの後は次の日まで店に入れない。
- **パチ屋**：店を選ぶと、上のタブで機種（福招き・三択侍・八門）を選び、機種のバナー（台の絵ができるまでは色と文字）と「設置状況」の表（台番・ハマり・BIG・確率、自己投資に応じて REG・差枚、空き／使用中。店員さんとの仲が90以上なら、その下にリセット／据え置き）を出す。台番を押して選び、「この台で遊ぶ」で座る。天井が近い台は金色に光る。
- **ホーム**の下のボタンは「寝る・ごはん・バイト・買い物」の4つのアイコン（ごはん・買い物は買い物画面のそのページへ）。
- **打つ画面**の上に、総ゲーム数・BIG・REG・合成確率を並べる。
- **買い物**：上のタブ（ごはん・息抜き・家具・不動産・裏市場）を押すか、横にスワイプして切り替える。裏市場は3日目から。
- **自分**：同じく上のタブとスワイプで、自己投資・収支（遊び始めてからの通算の収支・勝ち負けの回数・いちばん勝った日と、直近60回の日ごとの収支）・実績・設定（版の確認と更新、開発者画面の入口）。
- ページは、横に指を動かしたときだけめくれる（縦の動きは画面のスクロール）。
- **買うときの確認**：買い物（ごはん・息抜き・家具・不動産・裏市場・自己投資・目薬）はどれも、押すと下から「購入しますか？」の画面が出る（値段・今の所持金・買った後の所持金）。「購入する」で買い、「購入しました」の画面で、支払い・残りの所持金と、変わったゲージ（お腹 70 → 100 など）を見せる。お金が足りないものは押せず「お金が足りない」と出す。
- 部屋の絵はアニメ調に描き直す予定（家ごとの部屋の背景と、家具ごとに決まった置き場所）。絵ができるまでは今のドット絵とマス目の配置のまま。

### 9.5 見た目
- 紺と紫の夜のホールを背景に、パネルとボタンは金の縁取り、大事なボタン（パチ屋へ行く）は光沢のある赤に金の縁。ロゴ・所持金は金のグラデーションの文字、見出しは金の縁の飾り板。ゲージは丸いアイコン付き。台は金の枠、ストップボタンは赤い角の丸いボタン。ハマり台・達成した実績は金の光、負けた収支は赤で、金の縁取りの上でも状態が分かるようにする。ユーザーが見せた参考画像に合わせた。
- 色と縁取りは `src/style.css` の最後の「金の装飾テーマ」にまとめている。

### 9.6 台の液晶
- 打つ画面のリールの上に、台のバナーの絵（`public/banners/`）を背景にした液晶を置く。
- 知らせはすべてここに大きく出す：役の払い出し（「ベル +8枚 獲得」「ビタ成功 +32枚 獲得」など。リプレイは枚数を出さない）、取りこぼし、ボーナス確定・BIG・REG・ラッシュ・天井・チェリー重複、ボーナス終了（「BIG終了」「合計 n枚 獲得」。合計はボーナス中の払い出しの合計で、リプレイと賭けたメダルは数えない。八門は扉の払い出し）、扉チャンスの結果、実績。リールの下には出さない。オート中は払い出しを出さない。
- 知らせは順番に1つずつ出し、前の知らせを消さない。1つにつき約1.8秒（次が待っているときは約1.1秒、ふつうの払い出しは約0.7秒。`src/data/ui.ts`）。30枚以上の払い出しは金色。ボーナス中の残りゲームや狙い方などの案内は、液晶の下の帯に出し続ける。
- 店の台選びの機種のバナーにも同じ絵を使う。
